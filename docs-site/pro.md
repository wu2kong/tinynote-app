# 高级版

基础功能永久免费。高级版一次买断，面向需要更多空间、文章类笔记和 Git 同步的用户。

购买与价格以 [产品主页定价区](https://tinynote.wu2kong.com/) 为准。

## 对比

| | 基础版 | 高级版 |
| --- | --- | --- |
| 价格 | 免费 | 一次买断（Early Bird 见官网） |
| 空间数量 | 最多 5 个 | 不限 |
| 每空间笔记数 | 最多 100 个 | 不限 |
| 块笔记本、复制、搜索、主题 | 包含 | 包含 |
| 本地 Markdown / 备份 | 包含 | 包含 |
| 新建 Markdown / 文章笔记 | 每空间可创建 1 篇样例 | 不限 |
| Git 同步 | — | 包含 |
| 设备数 | — | 最多 3 台 |

## 如何开通

1. 在 [产品主页](https://tinynote.wu2kong.com/) 购买，或打开「设置 → 高级版」
2. 获得许可证密钥后，粘贴到「许可证密钥」并激活
3. 本机显示已激活后即可使用高级功能

许可证可在本机撤销激活，便于换设备。达到 3 台上限时，需要先在一台设备上撤销，再在新设备激活。

## 样例体验

未购买时，每个空间仍可为 Markdown 笔记、文章笔记各创建 1 篇样例，用于试用编辑体验。继续新建同类型笔记需要升级。

## 常见限制提示

应用会在到达上限时说明原因：

- 空间超过 5 个
- 单空间笔记超过 100 个
- 新建 Markdown / 文章笔记
- 使用 Git 同步模块
