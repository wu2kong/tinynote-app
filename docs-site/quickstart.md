# 快速上手

大约两分钟，从安装到复制出第一条笔记。

## 下载安装

1. 打开 [下载页](https://tinynote.wu2kong.com/download.html)
2. 按系统下载对应安装包
3. 安装并启动 TinyNote

macOS 若提示「无法验证开发者」，到「系统设置 → 隐私与安全性」中允许打开即可。

## 首次启动

首次打开会看到欢迎页，需要选择一个**存储文件夹**作为笔记库。

建议：

- 选一个你能长期使用的目录，例如 `~/TinyNote` 或某个已有 Git 仓库
- 不要选临时下载目录
- 之后可在「设置 → 数据」中更换，但笔记文件会留在原目录，需要自行迁移

选择完成后，应用会初始化默认空间，进入主界面。

## 创建第一条笔记

1. 左侧空间栏确认已选中一个空间；没有则点击「新建空间」
2. 在目录栏点击「新建块笔记本」，起一个名字，例如 `常用命令`
3. 在笔记栏点击「添加笔记」，写入标题和正文
4. 点击笔记块上的复制按钮，内容会进入剪贴板

之后的日常路径就是：**搜索 → 点复制 → 回到终端或编辑器粘贴**。

## 三种常用取用方式

### 在当前笔记里搜索

目录栏顶部可搜索当前空间中的笔记名称；笔记栏顶部可搜索当前笔记里的笔记块。

### 全局搜索

快捷键 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd>（Windows / Linux 为 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd>），可按空间名、笔记名、块标题或正文搜索整个笔记库。

### 最近打开

<kbd>Cmd</kbd>+<kbd>P</kbd> / <kbd>Ctrl</kbd>+<kbd>P</kbd> 打开最近笔记历史，适合在几个高频笔记本之间跳转。

## 建议的第一步结构

不必一开始就设计复杂分类。可以先这样拆：

```text
工作.tinynotes/
  ├── Shell/
  │   └── 常用命令.md
  ├── 前端/
  │   └── 片段.md
  └── Prompt.md
```

空间对应「生活场景」，目录对应「主题」，笔记对应「一组可复制条目」。等条目变多再细分即可。
