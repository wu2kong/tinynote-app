# 更新日志

完整安装包见 [下载页](https://tinynote.wu2kong.com/download.html)。

## v1.2.0

2026-08-19

- 三种笔记格式：块笔记本之外，新增 Markdown 笔记与文章笔记（所见即所得写作）
- 多语言界面：简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Italiano、Русский，并按系统语言自动切换
- 空间分组：空间可归入分组，支持下拉切换或折叠展示
- 反馈入口：设置中可一键复制版本信息并写信反馈
- 优化全局搜索入口、分组交互，以及文章笔记的新建与编辑体验
