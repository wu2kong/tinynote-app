# 更新日志

完整安装包见 [下载页](https://tinynote.wu2kong.com/download.html)。

## v1.2.3

2026-08-21

- Git 同步支持多个托管平台：GitHub、Gitee、GitLab、阿里云 Codeup、AtomGit 和自定义源，可在应用内授权、选仓并一键增删
- 新安装默认使用抹茶绿主题
- 去掉系统菜单中用处不大的「编辑」项

## v1.2.2

2026-08-21

- 支持导入 Markdown 笔记与目录，也可将文件或文件夹拖入窗口（普通 .md 会转为文章笔记）
- 可从系统菜单导出整个笔记库
- 首次选择存储目录或在设置中，可导入官方入门样例库
- 修复多工作区切换异常
- Markdown 预览中的外链改为在系统浏览器中打开
- 优化系统菜单，支持最近工作区管理

## v1.2.1

2026-08-20

- 文章笔记与 Markdown 笔记可在右键菜单中互相转换（只改后缀与编辑视图，正文不变）
- 新增帮助中心，并可从系统菜单打开
- 修复笔记保存时因防抖动导致内容被覆盖的问题
- macOS 使用 Sparkle、Windows 使用 WinSparkle 自动更新

## v1.2.0

2026-08-19

- 三种笔记格式：块笔记本之外，新增 Markdown 笔记与文章笔记（所见即所得写作）
- 多语言界面：简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Italiano、Русский，并按系统语言自动切换
- 空间分组：空间可归入分组，支持下拉切换或折叠展示
- 反馈入口：设置中可一键复制版本信息并写信反馈
- 优化全局搜索入口、分组交互，以及文章笔记的新建与编辑体验

## v1.1.0

2026-07-21

- 新增 AI 会话，并优化聊天交互
- 支持配置大模型提供商与模型
- 增强笔记编辑能力
- 新增历史记录管理与快捷访问
- 完善工作区与设置管理
- 优化笔记本点击体验、搜索及右键菜单

## v1.0.8

2026-06-18

- 提升 Git 稳定性
- 将 `configs.json` 迁移到笔记库根目录
- 侧边栏支持自由调整宽度

## v1.0.7

2026-06-16

- 增加主题切换
- 全局搜索
- 笔记本复制
