# 更新日志

完整安装包见 [下载页](https://tinynote.wu2kong.com/download.html)。

## v1.2.5

2026-08-25

### 新增功能

- 开放云盘同步：可把笔记库放到 iCloud、坚果云、OneDrive 等客户端正在同步的文件夹，由云盘负责上传下载
- Git 同步遇到冲突时，云端版本写入原文件，本机内容自动另存为「冲突版本」副本，笔记不会丢
- AI 模型设置支持添加多组自定义供应商，可同时连接多个 OpenAI 兼容服务

### 功能优化

- 同步设置页重新布局，Git 与云盘两种方式更易选择，源列表和日常操作更清晰

### 问题修复

- 修复 Windows 深色模式下自动更新说明文字看不清的问题

## v1.2.4

2026-08-22

### 新增功能

- Git 同步开放 TinyNote 官方托管（git.wu2kong.com），可在应用内授权、选择或新建仓库，国内访问更方便

### 功能优化

- 检查更新默认走 GitHub，无法访问时自动改用七牛云，仍失败可用蓝奏云手动下载
- 检查更新与下载安装包时给出明确的加载提示
- 关于页补充官网下载、GitHub Releases 与备用镜像入口
- 样例库从「数据」中独立为单独设置项
- 大模型配置改为可按需添加、移除供应商，界面更紧凑

### 问题修复

- 修复国内网络环境下因无法访问 GitHub 导致检查更新失败的问题
- 修复点击「检查更新」后界面反馈不及时、容易误以为无响应的问题

## v1.2.3

2026-08-21

- Git 同步支持多个托管平台：GitHub、Gitee、GitLab、阿里云 Codeup、AtomGit 和自定义源，可在应用内授权、选仓并一键增删
- 新安装默认使用抹茶绿主题
- 去掉系统菜单中用处不大的「编辑」项

## v1.2.2

2026-08-21

- 支持导入 Markdown 笔记与目录，也可将文件或文件夹拖入窗口（普通 .md 会转为文章笔记）
- 可从系统菜单导出整个笔记库
- 首次选择存储目录或在设置中，可导入官方入门样例库
- 修复多工作区切换异常
- Markdown 预览中的外链改为在系统浏览器中打开
- 优化系统菜单，支持最近工作区管理

## v1.2.1

2026-08-20

- 文章笔记与 Markdown 笔记可在右键菜单中互相转换（只改后缀与编辑视图，正文不变）
- 新增帮助中心，并可从系统菜单打开
- 修复笔记保存时因防抖动导致内容被覆盖的问题
- macOS 使用 Sparkle、Windows 使用 WinSparkle 自动更新

## v1.2.0

2026-08-19

- 三种笔记格式：块笔记本之外，新增 Markdown 笔记与文章笔记（所见即所得写作）
- 多语言界面：简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Italiano、Русский，并按系统语言自动切换
- 空间分组：空间可归入分组，支持下拉切换或折叠展示
- 反馈入口：设置中可一键复制版本信息并写信反馈
- 优化全局搜索入口、分组交互，以及文章笔记的新建与编辑体验
