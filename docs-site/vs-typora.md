# TinyNote vs Typora

[Typora](https://typora.io) 把 Markdown 写成接近纸面的文章：即时预览、导出 PDF、专注写作。它是编辑器，不是片段库。

TinyNote 也读 Markdown，但主路径是「一本块笔记里有很多条可复制内容」。另外还有 Markdown 笔记和文章笔记（所见即所得），给需要写整篇的人，那是高级版能力，不是产品中心。

如果你只是想打开一个 `.md` 写博客，用 Typora（或 VS Code）更合适。如果你打开应用是为了搜一条命令并复制，用 TinyNote。

## 怎么选

| | Typora | TinyNote |
| --- | --- | --- |
| 角色 | Markdown 编辑器 | 片段管理 + 复制 |
| 结构 | 打开单个文件或文件夹 | 空间 / 目录 / 笔记 / 块 |
| 复制 | 常规框选 | 每块一键复制 |
| 同步 | 看你自己怎么放文件 | 应用内 Git 与备份 |

两者可以共用同一批 Markdown：Typora 写长文，TinyNote 管命令本。
