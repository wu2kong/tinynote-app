# 组织与笔记

TinyNote 用真实文件夹表达结构：空间是带 `.tinynotes` 后缀的目录，里面的子文件夹是目录，`.md` 文件是笔记。

## 四层结构

```text
空间（.tinynotes 文件夹）
  └── 目录（可无限嵌套）
        └── 笔记（.md 文件）
              └── 笔记块（文件内的一条可复制内容）
```

### 空间

空间对应一个独立工作场景，例如「工作」「个人」「项目 A」。基础版最多 5 个空间，[高级版](/pro) 不限数量。

空间栏支持：

- 新建、重命名、删除、改图标
- 打开或复制对应文件夹路径
- 将空间归入分组，以下拉或折叠方式切换（见[设置手册](/settings)）

### 目录

目录就是普通文件夹，可无限嵌套。右键菜单可新建子目录、重命名、删除、移动、在文件管理器中打开。

删除目录会删除其中的笔记文件，操作不可撤销，请先确认。

### 笔记

目录栏可新建三种格式：

| 格式 | 说明 | 版本 |
| --- | --- | --- |
| 块笔记本 | 一个文件包含多条笔记块，每块可独立复制，TinyNote 的核心形态 | 基础版 |
| Markdown 笔记 | 整篇 Markdown 文档 | 高级版，每空间可先创建 1 篇样例体验 |
| 文章笔记 | 所见即所得写作 | 高级版，每空间可先创建 1 篇样例体验 |

基础版每个空间最多 100 个笔记。

## 笔记块

块笔记本里的每一条都是「笔记块」，也是复制的基本单位。

常用操作：

- **添加**：笔记栏底部添加；也可指定纯文本、Markdown、JSON、Bash、SQL、Python 等类型
- **复制正文**：点击块上的复制按钮
- **复制标题和正文 / 复制整个块**：右键菜单
- **粘贴为笔记**：若剪贴板是 TinyNote 块格式，可直接粘贴成新块
- **拖拽排序**：在笔记栏内上下拖动
- **创建副本**：复制一份当前块或整本笔记
- **提取链接**：从正文中列出 URL，便于复制或打开

右侧属性栏可改标题、正文、标签、内容类型，并查看创建/更新时间。需要大段编辑时，可打开全屏专业编辑器；JSON / SQL 支持格式化，Markdown 支持预览。

## 视图

笔记栏提供三种布局，可在栏顶切换，也可在设置里指定默认视图：

- **列表**：标题 + 预览，日常使用
- **卡片**：信息更完整，适合稍长的片段
- **紧凑**：尽量多显示条目，适合超大笔记本

## 源码模式

块笔记本可切换到源码模式，直接编辑底层 Markdown。适合批量调整 frontmatter，或对照外部编辑器的修改。

保存并解析后会重新拆成笔记块。如果源码格式损坏，解析可能失败，请先备份或通过 Git 还原。

## 搜索

| 入口 | 快捷键（macOS / 其他） | 范围 |
| --- | --- | --- |
| 目录栏搜索 | — | 当前空间的笔记名 |
| 笔记栏搜索 | — | 当前笔记中的块 |
| 当前工作区搜索 | <kbd>Cmd+F</kbd> / <kbd>Ctrl+F</kbd> | 当前工作区 |
| 全局搜索 | <kbd>Cmd+Shift+F</kbd> / <kbd>Ctrl+Shift+F</kbd> | 整个笔记库 |
| 最近打开 | <kbd>Cmd+P</kbd> / <kbd>Ctrl+P</kbd> | 打开历史 |

全局搜索可勾选匹配范围：空间名称、笔记名称、笔记块标题、笔记块内容。

## 拖拽与整理

空间、目录、笔记、笔记块都支持拖拽重排。目录栏也提供「移动到…」把笔记迁到其他目录。整理结构时，文件系统中的真实路径会一起变化。

## 导入与导出

可以把已有 Markdown 文件或文件夹拖进窗口，也可以用菜单导入 / 导出整库。规则见[导入与导出](/import-export)。
