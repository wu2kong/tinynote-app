# TinyNote vs Notion

两者都叫「笔记」，解决的却不是同一件事。

[Notion](https://www.notion.so) 是云端工作区：页面、数据库、权限、团队协作。适合写项目文档、建知识库、和同事共编。代价是客户端偏重、数据在账号里、复制一段命令往往要打开页面再框选。

TinyNote 是本地优先的片段工具。安装包约 5~10 MB，笔记是你磁盘上的 Markdown。每个笔记块有独立复制按钮，为 Shell 命令、JSON、Prompt 这种「每天贴很多次」的内容设计。

## 怎么选

| | Notion | TinyNote |
| --- | --- | --- |
| 定位 | 长文、数据库、团队 wiki | 零碎片段、一键复制 |
| 数据 | 云端账号 | 本地文件，可用 Git |
| 体积 | 通常上百 MB | 约 5~10 MB |
| 协作 | 强 | 靠 Git，不是实时共编 |
| 适合 | 会议纪要、项目页、团队文档 | 命令手册、配置片段、模板 |

可以一起用：Notion 写方案和周报，TinyNote 存「打开方案前要执行的那串命令」。
