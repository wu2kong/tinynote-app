# 隐私政策

最后更新：2026 年 8 月 23 日

## 1. 本地优先

TinyNote 默认将笔记、附件和配置保存在你选择的本地位置。我们不会主动收集、读取或上传你的笔记内容、文件名或本地备份。

只有在你主动配置 Git 同步、AI 服务或其他第三方服务时，相关内容才会按你的设置发送至所选服务商；这些服务由对应服务商的隐私政策约束。

## 2. 官网信息

官网使用浏览器本地存储保存语言和主题偏好，以便下次访问时恢复你的选择。该偏好数据保存在你的浏览器中，不会自动上传给 TinyNote。

## 3. 购买与许可证

当你购买 Pro 时，结账和交易信息由支付服务商 Dodo Payments 处理。我们会使用完成订单、发送许可证、处理退款或提供订单支持所必需的信息，例如购买邮箱、订单标识和许可证状态。请同时查阅支付服务商适用的隐私政策。

## 4. 数据控制

你可以随时删除本地笔记、清除浏览器站点数据，或在应用中撤销设备许可证。若需要查询、更正或删除与订单支持相关的个人信息，请联系 [tinynote-app@wu2kong.com](mailto:tinynote-app@wu2kong.com)。

## 5. 政策更新

我们可能因服务变化或法律要求更新本政策。更新后的版本会发布在此页面，并标注最后更新日期。
