# 隐私政策

最后更新：2026 年 9 月 1 日

## 1. 本地优先

TinyNote 默认将笔记、附件和配置保存在你选择的本地位置。我们不会主动收集、读取或上传你的笔记内容、文件名或本地备份。

只有在你主动配置 Git 同步或其他第三方服务时，相关内容才会按你的设置发送至所选服务商；这些服务由对应服务商的隐私政策约束。

## 2. 官网信息

官网使用浏览器本地存储保存语言和主题偏好，以便下次访问时恢复你的选择。该偏好数据保存在你的浏览器中，不会自动上传给 TinyNote。

## 3. 购买与许可证

TinyNote 提供两种购买方式，取决于你使用的版本：

**官网下载版**：当你通过官网购买 Pro 时，结账和交易信息由支付服务商 Dodo Payments 处理。我们会使用完成订单、发送许可证、处理退款或提供订单支持所必需的信息，例如购买邮箱、订单标识和许可证状态。请同时查阅支付服务商适用的隐私政策。

**Apple 应用商店版（Mac App Store / App Store）**：当你在应用内购买 Pro（含订阅或一次性买断）时，付款、账单与退款由 Apple 处理。我们不会收到你的支付卡号或其他 Apple ID 付款详情。应用仅通过 Apple StoreKit 验证购买权益状态，以便解锁 Pro 功能并支持“恢复购买”；相关交易信息受 [Apple 隐私政策](https://www.apple.com/legal/privacy/) 约束。

## 4. 数据控制

你可以随时删除本地笔记、清除浏览器站点数据，或在官网版应用中撤销设备许可证。App Store 版的订阅与购买，请通过 Apple ID 的订阅/购买设置管理。若需要查询、更正或删除与订单支持相关的个人信息，请联系 [tinynote-app@wu2kong.com](mailto:tinynote-app@wu2kong.com)。

## 5. 政策更新

我们可能因服务变化或法律要求更新本政策。更新后的版本会发布在此页面，并标注最后更新日期。
