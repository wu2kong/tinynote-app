# 导入与导出

TinyNote 的笔记库就是普通文件夹。除了在应用里新建笔记，也可以把已有 Markdown 文件引进来，或把整库拷出去。

## 导入 Markdown

入口：菜单「文件 → 导入笔记…」，或直接把文件 / 文件夹拖进窗口。

规则：

- 已带 `.blk.md` / `.mk.md` / `.writer.md` 标记的文件保持原格式
- 普通 `.md` 会转成文章笔记（`.writer.md`）
- 导入目录时会按文件夹结构生成对应目录

导入位置是当前选中的空间或目录。导入后可在目录栏里看到新笔记，必要时再拖到别的目录。

## 导出整库

菜单「文件 → 导出笔记库…」会把当前笔记库打包或复制到你指定的位置。适合换电脑、交给同事，或先做一份离线副本再改结构。

日常备份请用[本地备份](/backup)；多设备同步请用 [Git 同步](/sync)。

## 和文件系统的关系

因为空间是 `.tinynotes` 文件夹、笔记是 Markdown 文件，你也可以：

- 用访达 / 资源管理器直接拷贝笔记
- 用 VS Code 打开笔记库
- 用 Git 在应用外提交

只要不要改坏 frontmatter 分隔，块笔记本仍可被 TinyNote 正确解析。
