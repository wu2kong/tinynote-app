# TinyNote vs Notion

Both are “notes,” but they solve different jobs.

[Notion](https://www.notion.so) is a cloud workspace: pages, databases, permissions, and team editing. It is strong for project docs and wikis. The tradeoff is a heavier client, account-bound data, and a select-then-copy habit for commands.

TinyNote is local-first. The installer is about 5–10 MB. Notes are Markdown on disk. Each block has its own copy button, for shell commands, JSON, and prompts you paste many times a day.

## When to use which

| | Notion | TinyNote |
| --- | --- | --- |
| Job | Long docs, databases, team wikis | Snippets and one-click copy |
| Data | Cloud account | Local files, optional Git |
| Size | Often 100 MB+ | About 5–10 MB |
| Collaboration | Built-in | Git, not live co-editing |
| Typical use | Meeting notes, project pages | Command books, configs, templates |

They can sit side by side: write the plan in Notion, keep the commands you run before opening that plan in TinyNote.
