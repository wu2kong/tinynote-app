# TinyNote vs Typora

[Typora](https://typora.io) turns Markdown into a page you write on: live preview, PDF export, focus mode. It is an editor, not a snippet library.

TinyNote also speaks Markdown, but the main path is many copyable blocks in one notebook. It also has Markdown notes and article notes (WYSIWYG) for longer writing — those are Pro features, not the center of the product.

Use Typora (or VS Code) to draft a blog post. Use TinyNote to search a command and copy it.

## When to use which

| | Typora | TinyNote |
| --- | --- | --- |
| Role | Markdown editor | Snippet manager + copy |
| Structure | A file or a folder | Space / folder / note / block |
| Copy | Normal selection | One-click per block |
| Sync | However you store files | In-app Git and backup |

They can share the same Markdown tree: write long pieces in Typora, keep command books in TinyNote.
