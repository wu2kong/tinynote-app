# TinyNote vs Obsidian

[Obsidian](https://obsidian.md) and TinyNote both keep Markdown on disk and can use Git. The difference is what you do after you open a note.

Obsidian is built around long notes: backlinks, graph, plugins, daily notes. Copying a command is still find, select, copy.

TinyNote is built around blocks: one command, one JSON blob, one prompt. Search, then click copy. Structure is space → folder → note → block, mapped to directories, not a link graph.

## When to use which

| | Obsidian | TinyNote |
| --- | --- | --- |
| Core | Links and a knowledge network | Search and copy |
| Files | Mostly one note per file | One block notebook can hold many copyable items |
| Extensibility | Large plugin ecosystem | Small, focused app |
| Typical use | Research and a long-term PKM | Command books and ops snippets |

Keep the knowledge base in Obsidian and the pocket commands in TinyNote if you want both.
