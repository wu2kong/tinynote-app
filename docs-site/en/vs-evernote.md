# TinyNote vs Evernote

[Evernote](https://evernote.com) (and Yinxiang in China) is a cloud notebook: web clipper, attachments, account sync. It is good at collecting articles into one library.

TinyNote does not clip the web and does not require an account. Notes live in a folder you choose, as Markdown. It optimizes “find this command and copy it,” not “archive the whole page.”

## When to use which

| | Evernote | TinyNote |
| --- | --- | --- |
| Data | Cloud account | Local files |
| Content | Long notes, clippings, attachments | Short blocks, one-click copy |
| Size | Heavier client | About 5–10 MB |
| Sync | Vendor cloud | Git (including hosts in China and official Git) |
| Typical use | A research / clipping library | Commands you paste every day |

Keep long articles in Evernote if you already have them. Put the commands you paste daily in TinyNote.
