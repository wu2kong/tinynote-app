# Pro

Core features stay free forever. Pro is a one-time purchase for more spaces, article-style notes, and Git sync.

See current pricing on the [website](https://tinynote.wu2kong.com/).

## Compare

| | Free | Pro |
| --- | --- | --- |
| Price | $0 | One-time (early bird on the site) |
| Spaces | Up to 5 | Unlimited |
| Notes per space | Up to 100 | Unlimited |
| Block notebooks, copy, search, themes | Yes | Yes |
| Local Markdown / backup | Yes | Yes |
| New Markdown / article notes | 1 sample per type per space | Unlimited |
| Git sync | — | Yes |
| Devices | — | Up to 3 |

## Activate

1. Buy on the [website](https://tinynote.wu2kong.com/) or open Settings → Pro
2. Paste the license key and activate
3. When this machine shows as active, Pro features unlock

You can revoke activation on a device to free a slot. At the 3-device limit, deactivate one machine before activating another.

## Samples

Without Pro, each space can still create one Markdown sample and one article sample. Creating more of those types requires Pro.

## Limit messages

The app explains the reason when you hit a cap: more than 5 spaces, more than 100 notes in a space, new Markdown/article notes, or the Git sync module.
