# TinyNote vs Apple Notes

Apple Notes syncs almost invisibly across iPhone and Mac. It is right for lists, photos, and family sharing. It is not built for pasting a shell one-liner into a terminal, and there is no peer client on Windows or Linux.

TinyNote’s desktop app covers macOS, Windows, and Linux. Data is Markdown in a folder, with Git and [local backup](/en/backup). The mobile app can share the desktop library via an iCloud folder or Git (HTTPS); it still has fewer features than desktop.

## When to use which

| | Apple Notes | TinyNote |
| --- | --- | --- |
| Platforms | Apple devices | Desktop on three OSes; mobile is catching up |
| Data | iCloud | Local Markdown / Git |
| Copy | Normal selection | One-click on a block |
| Typical use | Life notes, shared lists | Commands, configs, templates |

Keep the grocery list in Notes. Keep SSH and kubectl in TinyNote.
