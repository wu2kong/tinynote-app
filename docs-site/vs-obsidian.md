# TinyNote vs Obsidian

[Obsidian](https://obsidian.md) 和 TinyNote 都把笔记存在本地 Markdown 里，都可以用 Git。差别在「打开笔记之后你要干什么」。

Obsidian 围绕一篇篇长文：双向链接、图谱、插件、日记。适合慢慢长成个人知识库。复制一段命令仍然是定位、框选、复制。

TinyNote 围绕「块」：一条命令、一段 JSON、一个 Prompt。搜索到了就点复制。组织方式是空间 → 目录 → 笔记 → 笔记块，直接对应文件夹，而不是链接网络。

## 怎么选

| | Obsidian | TinyNote |
| --- | --- | --- |
| 核心 | 链接与知识网络 | 检索与复制 |
| 文件 | 一篇一文件为主 | 一块笔记本可含多条可复制块 |
| 扩展 | 插件生态大 | 功能集中，体积小 |
| 适合 | 研究笔记、长期知识库 | 命令手册、运维片段 |

知识库用 Obsidian，口袋里的命令用 TinyNote，并不冲突。
