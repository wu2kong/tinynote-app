# 设置手册

打开方式：空间栏底部齿轮，或菜单「文件 → 设置…」。

设置分为：通用、数据、同步、备份、AI 模型、快捷键、高级版、反馈、关于。同步与备份见独立页面。

## 通用

| 选项 | 说明 |
| --- | --- |
| 显示语言 | 界面语言。未手动选择时跟随系统 |
| 颜色主题 | 极光蓝、青岩绿、樱花粉、纸墨灰、抹茶绿 |
| 深色模式 | 浅色 / 深色切换，会记住偏好 |
| 显示空间栏 | 隐藏后主界面更专注笔记区，需要时再打开 |
| 空间分组展示 | 禁用、下拉切换、折叠 |
| 隐藏元素边框 | 更极简的界面 |
| 默认视图 | 列表 / 卡片 / 紧凑 |
| 界面缩放 | 调整整体显示比例 |

菜单「视图」还可切换侧边栏和目录面板。

## 数据

这里管理笔记库路径，而不是笔记内容本身。

- **当前笔记库文件夹**：首次启动时选择的存储根目录
- **当前应用文件夹**：应用运行相关目录
- **多工作区注册表**：记录本机打开过的工作区，保存在用户 Home 目录，不会写入笔记库
- **当前工作区配置**：工作区级配置写在笔记库里，可以随 Git 一起同步

更换存储文件夹不会自动搬运旧文件。换路径前请先备份，或把原目录拷到新位置后再切换。

可在此复制路径，或在系统文件管理器中打开对应目录。

## 快捷键

修饰键在 macOS 为 <kbd>Cmd</kbd>，Windows / Linux 为 <kbd>Ctrl</kbd>。

| 快捷键 | 功能 |
| --- | --- |
| <kbd>Cmd/Ctrl</kbd> + <kbd>P</kbd> | 最近打开的笔记 |
| <kbd>Cmd/Ctrl</kbd> + <kbd>I</kbd> | AI 聊天 |
| <kbd>Cmd/Ctrl</kbd> + <kbd>F</kbd> | 当前工作区搜索 |
| <kbd>Cmd/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> | 全局搜索 |

## 关于与更新

「关于」页显示当前版本，并提供检查更新：

- **macOS / Windows**：走系统原生更新对话框
- **其他情况**：到 [下载页](https://tinynote.wu2kong.com/download.html) 获取安装包

菜单「TinyNote → 检查更新…」与此入口相同。
