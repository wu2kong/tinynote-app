# TinyNote vs 印象笔记 / Evernote

[印象笔记](https://www.yinxiang.com) 与 [Evernote](https://evernote.com) 是云端笔记本：剪藏网页、附件、跨设备同步、账号体系。适合把文章和资料收进一个云库。

TinyNote 不做剪藏引擎，也不绑定账号。笔记在你选的文件夹里，格式是 Markdown。它要快的是「找到这段命令并复制」，不是「把网页完整存下来」。

## 怎么选

| | 印象笔记 / Evernote | TinyNote |
| --- | --- | --- |
| 数据 | 云端账号 | 本地文件 |
| 内容 | 长文、剪藏、附件 | 短片段、块复制 |
| 体积 | 客户端较重 | 约 5~10 MB |
| 同步 | 官方云 | Git（含国内托管与官方 Git） |
| 适合 | 资料库、网页收藏 | 开发与运维的高频粘贴 |

已经用印象笔记存文章的人，不必迁移长文；把每天要贴的命令单独放到 TinyNote 即可。

见[应用概述](/app)与[下载页](https://tinynote.wu2kong.com/download.html)。
