# 服务条款

最后更新：2026 年 8 月 23 日

本条款适用于 TinyNote 官网、桌面与移动端软件，以及通过官网购买的 Pro 许可证。使用官网、下载软件或购买 Pro，即表示你同意本条款。

## 1. 软件与许可证

TinyNote 的基础功能可免费使用。Pro 为一次性购买的数字许可证；可用功能、价格和设备数量以 [官网定价](https://tinynote.wu2kong.com/#pricing) 与购买页展示为准。当前 Pro 许可证最多可在 3 台设备上激活；如需更换设备，请先在旧设备中撤销激活。

本条款不改变 TinyNote 开源代码所适用的开源许可证。对官网提供的商业服务、订单和许可证交付，以本条款为准。

## 2. 合理使用

请勿绕过、干扰或破坏许可证校验、支付流程、官网服务或其他用户的正常使用。不得使用盗用、伪造或未经授权取得的许可证密钥。

## 3. 内容与数据

你对自行创建、导入、同步或备份的笔记内容负责。请在进行删除、覆盖、同步或迁移操作前确认目标内容，并按需启用 [本地备份](/backup) 或 Git 同步。

## 4. 服务更新

我们可能更新软件功能、官网内容和本条款。重大调整会在官网或更新日志中说明；继续使用更新后的服务，表示你接受更新后的条款。

## 5. 免责声明与责任限制

TinyNote 按“现状”和“可用状态”提供。在适用法律允许的范围内，我们不对因使用或无法使用软件导致的间接、附带或后果性损失承担责任。法律赋予你的不可排除权利不受本条款影响。
