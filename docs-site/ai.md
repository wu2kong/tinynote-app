# AI 问答

TinyNote 可以接入 OpenAI 兼容的大模型，在应用内提问、整理片段或解释命令。配置只保存在本机，不会写入笔记库，也不会随 Git 同步。

快捷键：<kbd>Cmd</kbd>+<kbd>I</kbd> / <kbd>Ctrl</kbd>+<kbd>I</kbd>。

## 配置模型

打开「设置 → AI 模型」，按提供方填写：

| 提供方 | 说明 |
| --- | --- |
| OpenAI | 官方 API，例如 GPT 系列 |
| OpenCode Go / Zen | OpenAI 兼容订阅端点 |
| DeepSeek | 官方 DeepSeek API |
| 自定义 | 任意 OpenAI 兼容服务或本地模型 |

一般步骤：

1. 启用对应提供方
2. 填写 API Key（本地模型可留空）和 API URL
3. 「获取模型列表」，或手动添加模型名
4. 保存配置

保存后用快捷键打开聊天，在输入框上方选择模型。

## 聊天

- **Enter** 发送，**Shift+Enter** 换行
- 支持流式输出；可中途停止
- 可复制回复、重新生成
- 会话历史可新建、切换、删除
- 未启用任何带 Key 的提供方时，聊天会提示先去设置

## 安全注意

- API Key 只存在本机，不要把 Key 写进笔记内容
- Git 同步不会上传 AI 配置；换电脑需要重新填写
- 发送给模型的内容会经过对应服务商，不要粘贴密码、密钥等敏感信息
