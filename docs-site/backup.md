# 本地备份

备份会把笔记库和配置打包成 zip，适合不想依赖 Git、或需要额外留一份归档的情况。基础版即可使用。

![备份设置](/screenshots/backup.png)

## 设置备份文件夹

1. 打开「设置 → 备份」
2. 选择一个备份目录，建议与笔记库不在同一块磁盘或同一云同步文件夹
3. 点击「立即备份」

请先指定备份文件夹，否则无法开始备份。

## 备份内容

一次备份会打包：

- 当前笔记库中的空间、目录与笔记文件
- 相关配置文件

生成的 zip 会出现在备份文件夹中。列表会显示文件名、时间与大小。

## 恢复

应用内备份页主要用于创建和查看归档，恢复时：

1. 解压对应 zip
2. 确认其中的笔记库目录完整
3. 在「设置 → 数据」把存储路径指到解压后的笔记库，或把内容拷回原路径后重启 TinyNote

恢复会覆盖当前文件，操作前请先另存一份当前笔记库。

## 和 Git 同步怎么选

| | 本地备份 | Git 同步 |
| --- | --- | --- |
| 版本 | 基础版 | 高级版 |
| 形态 | zip 快照 | 提交历史 |
| 多设备 | 手动拷贝 zip | 拉取 / 推送 |
| 细粒度撤销 | 整包恢复 | 可按文件看 diff 并撤销 |
| 建议 | 定期本地保险 | 日常多设备主方案 |

两者可以一起用：日常用 Git，再定期打一份 zip。
